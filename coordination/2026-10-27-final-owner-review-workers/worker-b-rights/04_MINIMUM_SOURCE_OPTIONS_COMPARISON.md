Original QA IDs may be retained for traceability only if the new material is rights-reviewed and the QA semantics survive; test descriptions remain DESIGN_ONLY. No new files are currently authorized.

**C:** An independent owner-approved mock specification could allow controlled build planning without exposing research-file bytes, **if legally and technically viable**. That document itself requires provenance and consent to any cross-workspace use, and cannot silently reincorporate protected research wording. This option does not automatically grant code authorization.

**F02D optional add-on:** PR #10 source-light K48 metadata is **outside A's five** and NOT required for synthetic engineering. 10,990 additional bytes and one separate rights/owner decision if ever considered. Original F02 must not be included by default.
