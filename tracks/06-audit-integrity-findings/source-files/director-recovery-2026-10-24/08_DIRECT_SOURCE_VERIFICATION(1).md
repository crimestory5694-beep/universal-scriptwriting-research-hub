## Evidence standards

- `PASS`: original file supports the **narrow** stated point; not necessarily empirically validated.
- `CONDITIONAL`: file describes it, but scope, independence, quantitative validity or transfer is restricted.
- `FAIL`: source contradicts a material part of the reported claim.
- `UNVERIFIED`: original source or necessary validation has not been directly checked.
- *Internal mismatch:* cross-report data discrepancy, **never counted** as proof about original GitHub content.
