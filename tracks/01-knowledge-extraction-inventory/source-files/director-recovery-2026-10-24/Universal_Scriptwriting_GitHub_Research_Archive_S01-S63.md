## 0. Provenance and evidence-accuracy conventions
- This archive uses prior Batch 1 source notes and Batch 2/3 registers already in the conversation. The full original Batch 1 row-by-row priority/status table was not recoverable from the retained context; **S01–S23 labels with `^` are reconstruction from explicitly recorded file inspections, not an assertion that the exact original labels were recoverable**. Original missing priorities are marked `Unrecorded`, never silently estimated.
- `V1` = source-specific relevant content actually inspected. `V2` = repository identity/structure available, but substantive relevant content not inspected. `D` = discovery only. **V1 does not imply the method is validated, an author is authoritative, or all repository files have been read.** Where inspection was README-only/technical-only, that limitation is stated.
- `A` = original professional writing methodology/editorial guidance; `B` = academic paper/research implementation; `C` = actual narratives, examples, lesson texts or data-storytelling examples; `D` = evaluation, analytics or text/software tooling; `E` = Agent Skills/editorial/prompt workflow architecture; `F` = curated secondary collection. Multiple labels may apply. Classification here is a new archival taxonomy and does not change source verification.
- `Owner/author` distinguishes verified named authors from the repository account; **an owner handle is not proof of individual original authorship**. `not identified` / `not established` means the three reports do not support a stronger statement.
- Paths with clickable `blob/` links use branch/path combinations present in prior reports or recorded repository structures. Some original Batch 1 branch refs were not retained; these are kept as **literal exact paths without invented branch-specific links**. Repository home links are provided for all sources. Directory links are directories, not assertions that a particular nested file was read.
- Cumulative count is **63 distinct registered repository entries**, not 63 independent writing principles or scientific studies. Lower-trust tool/example sources are explicitly identified.
- `P1`, `P2`, `P3` are **reading priorities from previous reports** where recorded, not credibility grades. P1 is highest attention; P3 is limited or ancillary. `Unrecorded` marks the unrecoverable Batch 1 original priority.
